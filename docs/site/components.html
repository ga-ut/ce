Components

CE components are custom elements with a compact setup surface. They keep rendering, state, props, lifecycle cleanup, and handlers together.

Naming

The function name is converted to a custom element tag. This keeps the registration point short and avoids duplicating the tag string.

define(function UserMenu() {
  return html`<button>Account</button>`;
});

// Registers <user-menu>

Props

Props are declared beside the component and parsed from attributes. Use them for initial values and external configuration.

define(function PriceLabel({ props }) {
  return html`<span>${props.currency} ${props.amount}</span>`;
}, {
  props: {
    currency: String,
    amount: Number
  }
});

State

Signals are for local mutable values. Derived signals compute from other signals and update their rendered positions without rerunning unrelated DOM.

const count = signal(1);
const doubled = derived(() => count() * 2);

Cleanup

Use lifecycle cleanup for timers, observers, subscriptions, and request cancellation. Cleanup runs when the element disconnects.

CE docs describe the runtime surface, component model, release gates, and playground examples in-place.
