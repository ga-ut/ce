CE Public API

Public web runtime APIs are imported as named functions from the web entrypoint.

Import paths

import { define, html, signal, derived, effect, match } from "@ga-ut/ce/web";
import * as core from "@ga-ut/ce";
import * as coreOnly from "@ga-ut/ce/core";

Breaking change in v2.0.0

// Before
import { CE, html } from "@ga-ut/ce/web";

// After
import { define, html, signal, derived } from "@ga-ut/ce/web";

Stable API

define(component, options?)

define(function MyCounter({ props, lifecycle }) {
  const count = signal(props.initial ?? 0);
  const doubled = derived(() => count() * 2);

  lifecycle.cleanup(() => {
    // clear timers, listeners, or requests here
  });

  return html`
    <button onclick=${() => count.update((value) => value + 1)}>
      ${count} / ${doubled}
    </button>
  `;
}, {
  props: {
    initial: Number
  }
});
  • The function name becomes the custom element tag name: MyCounter registers my-counter.
  • props are parsed from attributes and tracked reactively.
  • lifecycle.cleanup runs when the element disconnects.

setEntryPoint(entryPoint: string)

Sets the router mount element. CE reuses an existing matching element or creates one.

navigate(path: string)

Supports history paths such as /users and hash paths such as #/users, then renders the route immediately.

html(strings, ...values)

html`
  <p>${signalValue}</p>
  <button onclick=${handler}>Save</button>
`

Template helper. Signals patch their text or attribute position without rerunning the whole render path.

Router placement decision

The router remains bundled but optional. It is used only when route, setEntryPoint, or navigate are used.

SemVer policy

  • MAJOR: signature changes, state lifecycle behavior changes, or routing contract changes.
  • MINOR: new optional params and non-breaking helpers.
  • PATCH: bug fixes and performance improvements with the same public contract.
