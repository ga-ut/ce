Usage

Use CE when a small custom element needs local state, scoped rendering, and direct event handling without a larger app framework.

Install the web runtime

Browser-facing components import named helpers from the web entrypoint. The package root stays core-only.

import { define, html, signal, derived, match } from "@ga-ut/ce/web";

Define a component

The component function owns setup and render. A function named ProductBadge registers the product-badge custom element.

define(function ProductBadge({ props }) {
  const selected = signal(false);
  const label = derived(() => selected() ? "Selected" : props.label);

  return html`
    <button onclick=${() => selected.update((value) => !value)}>
      ${label}
    </button>
  `;
}, {
  props: {
    label: String
  }
});

Render it in HTML

Once defined, the element is used like any other custom element. Props are read from attributes and converted by the declared prop type.

<product-badge label="In stock"></product-badge>

Generated static snapshot

The docs build runs the component once at build time and emits Declarative Shadow DOM without a headless browser.

Handle async states explicitly

Keep loading, success, and failure visible in render code. This makes state transitions easier to review and test.

const result = signal({ phase: "loading", data: null, error: null });

return html`
  ${match(result())
    .when((state) => state.phase === "loading", () => html`<p>Loading</p>`)
    .when((state) => state.phase === "success", ({ data }) => html`<p>${data.title}</p>`)
    .otherwise(({ error }) => html`<p>${error?.message ?? "Failed"}</p>`)}
`;
